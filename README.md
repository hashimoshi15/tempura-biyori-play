# 天ぷら日和 (Tempura Biyori)

下処理済みの海老を一本。打ち粉 → 衣 → 油 → 返し → 油切り → 盛り付けまで、**ぜんぶ箸の手作業**で揚げる天ぷら調理ゲームです。

## ▶ 遊ぶ / Play

**https://hashimoshi15.github.io/tempura-biyori-play/**

## 手の動き

| 動き | 料理の動作 |
| --- | --- |
| 押す | 箸でつかむ |
| 押したまま動かす | 運ぶ |
| 器の上で止めて上下 | 下ろす・持ち上げる |
| 器の中で左右 | 転がす (衣をまとわせる・油の中で返す) |
| 止めて保持 / 小さく振る | 余分な衣や油を落とす |
| 離す | その場で落ちる |
